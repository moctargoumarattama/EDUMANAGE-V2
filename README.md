# 📚 LabeeB Arabic

### Apprendre avec douceur 🌙

## 🧠 Présentation

**LabeeB Arabic** est une plateforme e-learning dédiée à l’apprentissage de la langue arabe.
Inspirée du concept de Duolingo, cette application propose une approche simple, progressive et intuitive pour apprendre efficacement.

L’objectif est de permettre aux utilisateurs de :

* suivre leurs cours
* visualiser leur progression
* apprendre à leur rythme dans un environnement moderne

## 🚀 Installation

Clonez le projet :

```bash
git clone https://github.com/moctargoumarattama/EDUMANAGE-V2.git
cd EDUMANAGE-V2
```

Créez un environnement virtuel :

```bash
python -m venv .venv
.venv\Scripts\activate
```

Installez les dépendances :

```bash
pip install -r requirements.txt
```

Lancez l’application :

```bash
python run.py
```

---

## 🔑 Accès

* Les nouveaux comptes étudiants doivent être validés par un administrateur avant utilisation.
* Une fois connecté, l’utilisateur accède à ses cours et à son suivi.
